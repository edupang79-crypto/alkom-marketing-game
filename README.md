# 캠페인 실습 노트

롯데 LIFT 부산3반 **3-2 캠페인 기획 실습**(동래점 「다시, 출근룩」)과 **3-1 프로모션 기획 실습**(케이스 C 「가을 스타일링 페어」) 워크시트 ①~⑪을 웹에서 작성하는 실습 앱입니다.

## 기능
- 워크시트 22장(과정별 ①~⑪)을 칸 단위로 입력하고 브라우저에 자동 저장
- **빨간펜 모범답안**: 칸마다 모범답안을 겹쳐 보거나 숨기기, 시트 단위로 채우기·비우기
- **자동 점검**
  - 주/부 목표를 하나씩 골랐는지, 인사이트에 상황·근거·유형이 있는지
  - 채널·예산 비중이 합계 100%인지, ⑤ 채널과 ⑧ 예산이 서로 맞는지
  - 1인당 획득 비용, 코디·상담 수용량, IMC 단계마다 핵심어가 이어지는지
  - 감정 곡선, 200평 공간 배분, 20% 삭감안, 손익분기·ROI 계산
- ⑩ 1페이지 기획안: 앞 시트 내용으로 빈 칸 초안을 채우고 미리보기
- ⑪ 발표 시간과 상호 평가 점수 합계
- 전체 내용을 표 형식 텍스트로 복사, 백업 코드로 다른 기기에 옮기기

## 실행
`index.html`을 브라우저로 열면 됩니다. 서버나 설치가 필요 없습니다. GitHub Pages에 올리면 바로 배포됩니다.

## 수정
- 워크시트 내용·모범답안: `src/data.js`
- 계산·화면 동작: `src/app.js`
- 레이아웃·스타일: `src/shell.html`

수정한 뒤 `./build.sh`를 실행하면 `index.html`이 다시 만들어집니다.
