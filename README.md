# 캠페인 실습 노트

롯데 LIFT 부산3반 **3-2 캠페인 기획 실습** 조별 미션 앱입니다. 각 조가 롯데백화점 부산 4개점(A 부산본점 · B 광복점 · C 동래점 · D 센텀시티점) 또는 자유 선택(E) 가운데 미션 하나를 골라 케이스 시트와 실습 ①~⑪ 워크시트를 완성합니다.

## 흐름
1. **미션 선택**: 점포별 규모 · 주 고객 · 상황 · 가치 · 목표 유형을 비교하고 하나를 고릅니다.
2. **케이스 시트**
   - 공개 수치를 출처 기사 링크와 함께 보여 줍니다.
   - 조가 직접 찾을 항목마다 바로 열 수 있는 사이트 링크가 붙어 있습니다.
   - 목표 유형 · 기간 · 예산은 조가 정합니다.
3. **실습 ①~⑪**
   - 각 시트 위에 "이 시트에 쓸 자료" 링크가 있습니다.
   - 입력할 때마다 자동 점검이 다시 계산됩니다(주/부 목표, 채널·예산 100%, ⑤↔⑧ 교차 점검, 1인당 획득 비용, 수용량, IMC 핵심어 등).
   - ⑩에서 앞 시트 내용으로 원페이퍼 초안을 채웁니다.
4. **자료 찾기**
   - 참고 사이트 17곳을 분류별로 모았습니다. 네이버 데이터랩, KOSIS, DART, 블랙키위, 오픈서베이, 대학내일20대연구소, 행안부 인구통계 등이 들어 있습니다.
   - 사이트마다 검색 방법을 적었고, 누르면 새 탭에서 바로 열립니다.
   - 블랙키위와 네이버 뉴스는 키워드를 넣으면 검색 결과로 바로 연결됩니다.

작성 내용은 미션별로 브라우저에 자동 저장됩니다. "내보내기 · 백업"에서 제출용 텍스트를 복사하거나 백업 코드로 다른 기기에 옮길 수 있습니다.

## 조별 라운드와 강사방
- **조 화면**
  - 우리 조(1~12조)를 고른 다음 미션을 고릅니다.
  - 같은 조 조원이 같은 번호를 고르면 한 시트를 함께 쓰고, 입력은 몇 초 안에 서로에게 보입니다.
  - 시트마다 아래에 "라운드 제출하기" 버튼이 있습니다.
- **강사방** (소유자 · 편집자, 또는 강사 코드)
  - 라운드 진행:
    - 라운드(0 케이스 시트, ①~⑪)를 골라 시작하면 제한 시간 타이머가 돌고, 조 화면에서는 그 라운드까지만 열립니다.
    - 제한 시간: 0 30분(가정) · ① 35 · ② 35 · ③ 40 · ④ 30 · ⑤ 40 · ⑥ 35 · ⑦ 40 · ⑧ 30 · ⑨ 35 · ⑩ 45 · ⑪ 60분
  - 조 × 라운드 표: 칸마다 제출(✓), 작성 중(%), 비어 있음(·)이 표시됩니다.
  - 라운드별 모든 조: 같은 시트를 모든 조가 쓴 모습으로 나란히 보여 줍니다. 자동 점검 결과도 함께 나옵니다.
  - 한 조의 모든 시트: 한 조의 0~⑪을 이어서 봅니다.
- **실시간 공유 조건**: 조원이 이 앱에서 작성하려면 아티팩트를 조직에 "참여자(Contributor)" 이상으로 공유해야 합니다.
- **공유가 안 될 때**
  - 조가 "백업 코드 복사"로 코드를 보내고, 강사가 강사방의 "제출 코드로 모으기"에 붙여 넣습니다.
  - 붙여 넣은 결과는 강사 브라우저에만 저장됩니다.

## 칸 아래 도움말
- **회색 예시 (항상 보임)**
  - 출처 · 측정 방법 · 수치 · 일정처럼 형식을 맞추면 되는 칸에 붙어 있습니다.
  - 숫자와 이름은 ○○으로 비워서 적는 모양만 보여 줍니다.
- **막히면 힌트 (접혀 있음)**
  - 인사이트 · 슬로건 · 남길 문장 · 스토리 · 판단 질문처럼 조가 스스로 생각해야 하는 칸에 붙어 있습니다.
  - 문장 틀 대신 질문만 보여 주므로, 네 조의 결과가 한 모양으로 모이지 않습니다.
- 조가 먼저 써 본 뒤 강사 모드에서 동래점 예시 답안을 띄워 비교하는 순서를 권합니다.

## 강사 모드
"내보내기 · 백업" → 강사 모드에 코드 `lift`를 넣으면 다음이 열립니다.
- 각 칸에 3-2 동래점 「다시, 출근룩」 예시 답안이 빨간 글씨로 보입니다. 시트마다 예시 답안으로 채울 수도 있습니다.
- 3-1 케이스 C 「가을 스타일링 페어」 모범답안(강사 참고용)을 볼 수 있습니다.

코드는 `src/app.js`의 `INSTRUCTOR_CODE`에서 바꿉니다.

## 서체
전체 화면에 [Pretendard](https://github.com/orioncactus/pretendard)(OFL 1.1, 무료)를 씁니다. 한글 2,350자를 담은 서브셋이 `fonts/`에 있습니다.

## 실행 · 수정
- `index.html`을 브라우저로 열면 됩니다. `fonts/` 폴더와 함께 두십시오. GitHub Pages에 그대로 올릴 수 있습니다.
- 미션 · 사이트: `src/cases.js` / 워크시트 · 예시 답안: `src/data.js` / 칸 아래 도움말: `src/examples.js` / 동작: `src/app.js` / 화면: `src/shell.html`
- 수정한 뒤 `./build.sh`를 실행하면 `index.html`이 다시 만들어집니다.
