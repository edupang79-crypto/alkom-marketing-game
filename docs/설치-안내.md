# 가입 없이 쓰는 실습 앱 — 강사 설치 안내 (한 번만)

교육생은 QR만 찍으면 로그인 없이 바로 씁니다. 강사는 아래 두 가지를 한 번만 해 두면 됩니다.

## 1. 웹사이트 켜기 (GitHub Pages · 1분)

1. https://github.com/edupang79-crypto/alkom-marketing-game → **Settings** → 왼쪽 **Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `claude/laughing-edison-n1avro` · 폴더 `/ (root)` → **Save**
4. 1~2분 뒤 주소가 열립니다: https://edupang79-crypto.github.io/alkom-marketing-game/

여기까지만 해도 앱은 열립니다. 다만 실시간 강사방은 2번을 마쳐야 켜집니다
(그 전에는 조가 "백업 코드"를 보내고 강사방 "제출 코드로 모으기"로 받습니다).

## 2. 실시간 저장소 만들기 (Firebase · 무료 · 5분)

1. https://console.firebase.google.com → Google 계정으로 로그인 → **프로젝트 추가**
   - 이름 예: `campaign-lab` · Google 애널리틱스는 꺼도 됩니다
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` · **프로덕션 모드**로 시작
3. Firestore 화면의 **규칙** 탭 → 저장소의 `firestore.rules` 내용을 그대로 붙여 넣고 **게시**
4. 왼쪽 위 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱 → 웹(</>)** → 앱 이름 입력 → 등록
5. 화면에 나오는 `const firebaseConfig = { apiKey: ..., projectId: ..., ... }` 부분을 복사해 Claude에게 보내 주십시오.
   (이 값은 비밀번호가 아니라 웹 앱 주소 같은 공개 설정값입니다.)
   직접 넣으려면 저장소의 `firebase-config.js`에서 `window.FIREBASE_CONFIG = null;`을
   `window.FIREBASE_CONFIG = { ...복사한 내용... };`으로 바꾸면 됩니다.

## 수업 당일

1. 강사: 사이트 → 위 **강사** 버튼 → 비밀번호 `0000` → **강사방**
2. 강사방의 **QR 크게 띄우기**를 화면에 띄웁니다.
3. 교육생: QR 찍기 → 우리 조 고르기 → 작성자 이름 쓰기. 가입 · 로그인은 없습니다.
4. 교육생도 "내보내기 · 백업 → 원본 시트 PPT 내려받기"로 자기 조 PPT를 받을 수 있습니다.
5. 수업이 끝나면 강사방 **다시 시작**으로 모든 조 기록을 지웁니다.

## 알아 둘 점

- 로그인이 없으므로 주소를 아는 사람은 누구나 쓸 수 있습니다. 강사 비밀번호 `0000`은 화면을 나누는 용도일 뿐 보안 장치가 아닙니다. 개인정보는 적지 않도록 안내하십시오.
- Firebase 무료 사용량(하루 읽기 5만 · 쓰기 2만 회)은 4개 조 · 30명 수업에 충분합니다.
